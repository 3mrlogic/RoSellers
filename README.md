# RoSellers - منصة بيع أنظمة روبلوكس

موقع RoSellers هو منصة احترافية لبيع أنظمة ومنتجات روبلوكس المتبرمجة والمصممة بالكامل مع GUI احترافي.

## 🎮 عن الموقع

RoSellers هي منصة متخصصة في بيع الأنظمة والمنتجات البرمجية لمجتمع روبلوكس. نقدم:
- أنظمة متاجر إلكترونية متكاملة
- أنظمة إدارة لاعبين وبيانات
- أنظمة إحصائيات وتحليلات
- أنظمة عملات ومكافآت
- أنظمة دردشة متقدمة
- واجهات GUI احترافية

## ✨ المميزات الرئيسية

### التصميم
- تصميم عصري بأسلوب meme مع GIFs تفاعلية
- تأثيرات Glassmorphism احترافية
- Particles Background متحركة
- Gradient Text Animation
- Scroll Progress Bar
- Dark Mode أساسي
- متجاوب مع جميع الأجهزة (Responsive)
- دعم RTL للغة العربية

### التفاعلية
- Micro-interactions متقدمة
- تأثيرات hover على جميع العناصر
- FAQ Section تفاعلية
- Testimonials Section مع تقييمات
- عدادات تفاعلية
- رسوم متحركة سلسة

## 🚀 التشغيل

### المتطلبات
- Node.js (للخادم)
- متصفح حديث

### التشغيل السريع
```bash
# تثبيت التبعيات
npm install

# تشغيل الخادم
npm start

# أو فتح index.html مباشرة في المتصفح
```

### استخدام Live Server
1. قم بتثبيت Live Server في VS Code
2. انقر بزر الماوس الأيمن على `index.html`
3. اختر "Open with Live Server"

## 🎨 الأقسام الرئيسية

1. **القائمة العلوية (Navigation)**: شريط تنقل ثابت مع Scroll Progress Bar
2. **قسم البطل (Hero)**: قسم رئيسي مع Particles Background و GIFs
3. **المميزات (Features)**: عرض مميزات المنصة مع GIFs تفاعلية
4. **المنتجات (Products)**: عرض المنتجات المتاحة
5. **آراء العملاء (Testimonials)**: تقييمات العملاء
6. **الأسعار (Pricing)**: خطط الاشتراك المختلفة مع GIFs
7. **الأسئلة الشائعة (FAQ)**: قسم الأسئلة الشائعة التفاعلي
8. **التواصل (Contact)**: نموذج التواصل ومعلومات الاتصال
9. **التذييل (Footer)**: معلومات الموقع

## 🛠️ التقنيات المستخدمة

### Frontend
- **HTML5**: هيكل الصفحة
- **Tailwind CSS**: إطار العمل للتنسيق

- **Google Fonts**: خط Cairo للعربية

### Backend (قيد التطوير)
- **Node.js**: خادم JavaScript
- **Express.js**: إطار عمل الويب

## 💡 التخصيص

### تغيير الألوان
عدل ملف `frontend/tailwind.config.js`:

```javascript
colors: {
  primary: '#6366f1',    // اللون الأساسي
  secondary: '#8b5cf6',  // اللون الثانوي
  dark: '#0f172a',       // الخلفية الداكنة
  darker: '#020617',     // الخلفية الأكثر دكنة
}
```

### تعديل بيانات العملاء
عدل ملف `config/testimonials.json`:

```json
{
  "testimonials": [
    {
      "name": "اسم العميل",
      "role": "الوظيفة",
      "rating": 5,
      "comment": "الرأي",
      "avatar": "رابط الصورة"
    }
  ]
}
```

### تعديل بيانات المنتجات
عدل ملف `config/products.json`
